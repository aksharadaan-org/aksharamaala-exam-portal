Aksharamaala Exam Portal

A beginner-friendly guide for building a separate student exam app with a local practice database. Start with the working parts, then use each chapter as a blueprint for the screens still to build.

New to this project? Read Start here first. It explains what the app, API, and database do, what already works, and the order to follow. Keep Words explained open while you work.

One rule to remember

The browser previews are clickable teaching examples. The PostgreSQL database and student API are working local code. The Expo phone app is currently a connection checker. Build the real phone screens from the guide and connect them to the student API.
