Run the reference implementation

Extract the download, start Docker and use Node 22.13+ in the 22.x line, and run these commands from the repository root. The first refresh creates two schools, two learners, four dimensions, 24 synthetic qualities and five stage windows. The mobile starter checks sign-in against the local service.

npm ci
npm run db:start
npm run db:refresh
npm test
npm start
# Second terminal, from the repo root
cd mobile
npm ci
npm start

The web walkthroughs are interactive design fixtures. The download runs a separate student API and PostgreSQL 17 database in Docker. The API reference identifies implemented operations and proposed staff contracts.
