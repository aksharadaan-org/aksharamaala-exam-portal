Student app

Tap the exam tile or a practice reminder. Complete the baseline to unlock practice 1. The walkthrough remembers the signed-in demo learner and saved answers in this browser.

How to use this phone preview

Browser preview Click Exam tile, sign in as demo-a with code 246810, pick at least one quality, and finish Baseline. This preview saves its sample state in this browser only. It does not call PostgreSQL or the local API.

When building the real Expo app: use the screen on the left as a visual example. The box on the right tells you which API call to make. Wait for the API to confirm a saved answer before moving to the next question. The existing mobile/App.tsx only checks the API connection; the full screen flow is still to build.

Try an error: Select an answer, turn on “Simulate answer-save failure,” and tap Save and continue. The choice stays visible. Turn the switch off and tap again. That is the behavior the real app needs when a network request fails.
