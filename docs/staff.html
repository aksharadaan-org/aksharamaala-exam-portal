Staff console

Explore the same synthetic roster through a school or programme view. Report filters apply to both the counts on screen and the CSV export.

This is a future staff screen

Design only The controls below use invented data held in this browser tab. They do not read or change PostgreSQL. The student API does not have working staff routes yet.

Try it: leave the role as School viewer and notice that the school cannot be changed. Choose Programme administrator to see roster editing, question drafts, scheduling, and reports. A real staff API must check the role on the server; hiding a button alone does not protect data.

What each staff tab is for

TabWhat a staff member doesWhat a real implementation needs
ReportsFilter a school and read eligible, submitted, and completion counts; download CSV.Working staff report routes and server-checked school access.
RosterView sample students; an administrator can add one.Staff sign-in, school list, student list, create and edit routes.
Question bankEdit English and Telugu text, save a draft, publish a version.Validation, versioned questions, and safe publishing routes.
SchedulesSet opening and closing dates for a stage.Schedule edit route, UTC storage, and conflict handling.

This staff prototype uses a separate two-learner reporting fixture in tab memory. Refreshing the page restores the fixture. Staff service routes and their required authorization are specified in the API reference.
